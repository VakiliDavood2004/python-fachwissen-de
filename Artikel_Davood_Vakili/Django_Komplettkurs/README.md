# 📘 Kompletter Django-Kurs – Deutschsprachige Anleitung

Dieser Ordner enthält eine Sammlung von Lernmaterialien auf Deutsch über das Django-Framework. Schritt für Schritt werden die wichtigsten Konzepte der Webentwicklung mit Django vermittelt. Der Kurs richtet sich an Studierende, Einsteiger in die Webentwicklung und alle, die Django strukturiert erlernen möchten.

---

## 📂 Dateistruktur

| Nr. | Dateiname | Beschreibung |
|-----|-----------|--------------|
| 1 | `1-django-einführung.md` | Einführung in Django, Geschichte, Vorteile und Anwendungsbereiche |
| 2 | `2-django-projektstruktur.md` | Überblick über die Projektstruktur in Django, inklusive manage.py, settings und Apps |
| 3 | `3-django-modelle-und-datenbank.md` | Erstellung von Modellen, Datenbankverbindungen und Migrationen |
| 4 | `4-django-views-und-urls.md` | Definition von Views, URL-Routing und Pfadverwaltung |
| 5 | `5-django-templates-und-forms.md` | Arbeit mit Templates, Formularen und Darstellung von Daten in HTML |
| 6 | `6-django-auth-und-benutzerverwaltung.md` | Authentifizierungssystem von Django, Benutzerverwaltung, Login und Registrierung |
| 7 | `7-django-rest-api.md` | Erstellung von APIs mit Django REST Framework zur Kommunikation mit Frontend oder anderen Anwendungen |
| 8 | `8-django-deployment.md` | Deployment eines Django-Projekts auf einem Server, Sicherheitskonfiguration und Optimierung |
| 9 | `9-django-quiz.md` | Sammlung von 80 Quizfragen zur Wiederholung der Inhalte aus Kapitel 9 (Templates und Forms) |
| 10 | `10-django-quiz-lösungen.md` | Vollständige Antworten zu den Quizfragen in Deutsch, Englisch und Persisch |

---

## 🎯 Kursziel

Ziel dieses Kurses ist es, die Teilnehmer:innen schrittweise mit Django vertraut zu machen – von den Grundlagen bis zur API-Erstellung und zum Deployment. Die Quiz-Dateien dienen zur Wiederholung, Übung und Selbstbewertung.

---

## 🧭 Nutzungshinweise

Für eine optimale Nutzung des Kurses wird empfohlen:

- Die Dateien in numerischer Reihenfolge zu lesen.
- Nach dem Studium der Dateien 1 bis 8 das Quiz in Datei 9 zu absolvieren.
- Anschließend die Lösungen in Datei 10 zu überprüfen.
- Bei Bedarf die Übersetzungen in Persisch und Englisch zur besseren Verständlichkeit zu nutzen.

# 📘 Complete Django Course – English Guide

This folder contains a collection of educational files in German about the Django framework. Step by step, it teaches the core concepts of web development with Django. The course is designed for students, beginner developers, and anyone interested in learning Django in a structured way.

---

## 📂 File Structure

| No. | Filename | Description |
|-----|----------|-------------|
| 1 | `1-django-einführung.md` | Introduction to Django, its history, benefits, and use cases |
| 2 | `2-django-projektstruktur.md` | Overview of Django project structure including manage.py, settings, and apps |
| 3 | `3-django-modelle-und-datenbank.md` | Creating models, connecting to databases, and handling migrations |
| 4 | `4-django-views-und-urls.md` | Defining views, URL routing, and path management |
| 5 | `5-django-templates-und-forms.md` | Working with templates, forms, and rendering data in HTML |
| 6 | `6-django-auth-und-benutzerverwaltung.md` | Django’s authentication system, user management, login and registration |
| 7 | `7-django-rest-api.md` | Building APIs using Django REST Framework for frontend or external integrations |
| 8 | `8-django-deployment.md` | Deploying Django projects to servers, security configurations, and optimization |
| 9 | `9-django-quiz.md` | A set of 80 quiz questions to review the concepts from Chapter 9 (Templates and Forms) |
| 10 | `10-django-quiz-lösungen.md` | Complete answers to the quiz questions in German, English, and Persian |

---

## 🎯 Course Objective

This course is designed to guide learners step-by-step through Django — from the basics to API development and deployment. The quiz and solution files are included for review, practice, and self-assessment.

---

## 🧭 How to Use

To get the most out of this course:

- Study the files in numerical order.
- After completing files 1 to 8, take the quiz in file 9.
- Then check your answers using file 10.
- Use the Persian and English translations for better understanding if needed.

# 📘 دوره کامل Django – راهنمای فارسی

این پوشه شامل مجموعه‌ای از فایل‌های آموزشی به زبان آلمانی درباره‌ی فریم‌ورک Django است که به‌صورت مرحله‌به‌مرحله مفاهیم اصلی توسعه وب با Django را آموزش می‌دهد. این دوره برای دانشجویان، توسعه‌دهندگان تازه‌کار و علاقه‌مندان به یادگیری Django طراحی شده است.

---

## 📂 ساختار فایل‌ها

| شماره | نام فایل | توضیح |
|-------|----------|-------|
| 1 | `1-django-einführung.md` | معرفی اولیه فریم‌ورک Django، تاریخچه، مزایا و کاربردها |
| 2 | `2-django-projektstruktur.md` | بررسی ساختار پروژه در Django و اجزای اصلی آن مانند manage.py، settings و apps |
| 3 | `3-django-modelle-und-datenbank.md` | آموزش ساخت مدل‌ها، ارتباط با پایگاه داده و مهاجرت‌ها |
| 4 | `4-django-views-und-urls.md` | نحوه تعریف viewها، اتصال آن‌ها به URLها و مدیریت مسیرها |
| 5 | `5-django-templates-und-forms.md` | کار با قالب‌ها (templates)، فرم‌ها و نحوه نمایش داده‌ها در HTML |
| 6 | `6-django-auth-und-benutzerverwaltung.md` | سیستم احراز هویت Django، مدیریت کاربران، ورود و ثبت‌نام |
