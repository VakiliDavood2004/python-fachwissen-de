# 🇩🇪 Deutsch

Hallo!  
Dieses Projekt enthält eine Sammlung wichtiger deutscher Vokabeln für verschiedene Niveaus – von **A1 (Anfänger)** bis **B2 (fortgeschrittenes Mittelstufe)**.  
Ziel ist es, persischsprachigen Lernenden zu helfen, Wörter auf einfache, praktische und strukturierte Weise zu lernen.

### 🎯 Projektziele

- Bereitstellung wichtiger und häufiger Wörter für jedes Niveau  
- Genaue Übersetzung ins Persische und Englische  
- Beispielsätze zur besseren Verständlichkeit (nur in A2 und B1)  
- Vorbereitung der Dateien für Selbststudium, Unterricht oder Sprachprüfungen

### 📂 Dateistruktur

Jedes Niveau hat eine eigene Datei:

- `wortschatz_A1.md` → Grundwortschatz für den Einstieg  
- `wortschatz_A2.md` → Alltagsvokabeln mit etwas mehr Komplexität  
- `wortschatz_B1.md` → Nützliche Wörter für Gespräche und Schreiben  
- `wortschatz_B2.md` → Fortgeschrittene Wörter für Studium, Arbeit und Diskussionen

Jede Datei enthält:

- Deutsches Wort  
- Übersetzung ins Persische und Englische  
- Beispielsatz (nur in A2 und B1)  
- Thematische Kategorien (falls nötig)

### 🛠️ Verwendung

1. Öffne die Datei für dein Niveau.  
2. Lies die Wörter und versuche, die Beispielsätze zu verstehen.  
3. Notiere unbekannte Wörter und übe sie regelmäßig.  
4. Nutze die Dateien für Karteikarten, Schreibübungen oder Gespräche.

### 🔮 Zukünftige Pläne

- Hinzufügen von Dateien für **C1 und C2**  
- Gestaltung von PDF- und Druckversionen  
- Integration von Übungen und kleinen Tests für jedes Niveau  
- Entwicklung einer App oder eines Online-Tools zum Vokabeltraining

### 🤝 Zusammenarbeit & Feedback

Wenn du Vorschläge zur Verbesserung hast oder mitarbeiten möchtest, freue ich mich auf deine Nachricht.  
Du kannst mich per E-Mail oder über die Kommentare kontaktieren.

**Viel Erfolg beim Deutschlernen! 🇩🇪✨**

# 🇬🇧 English

Hello!  
This project contains a collection of essential German vocabulary for different levels – from **A1 (beginner)** to **B2 (upper intermediate)**.  
Its goal is to help Persian-speaking learners study words in a practical, simple, and organized way.

### 🎯 Project Goals

- Provide important and commonly used words for each level  
- Accurate translation into Persian and English  
- Example sentences for better understanding (only in A2 and B1)  
- Prepare files for self-study, classroom use, or language exams

### 📂 File Structure

Each level has its own file:

- `wortschatz_A1.md` → Basic vocabulary for getting started  
- `wortschatz_A2.md` → Everyday vocabulary with more complexity  
- `wortschatz_B1.md` → Useful words for conversation and writing  
- `wortschatz_B2.md` → Advanced vocabulary for study, work, and discussions

Each file includes:

- German word  
- Persian and English translation  
- Example sentence (only in A2 and B1)  
- Thematic categories (if needed)

### 🛠️ How to Use

1. Open the file for your level.  
2. Read the words and try to understand the example sentences.  
3. Write down unfamiliar words and practice them.  
4. Use the files for flashcards, writing practice, or speaking exercises.

### 🔮 Future Plans

- Add files for **C1 and C2**  
- Design printable and PDF versions  
- Include exercises and mini-tests for each level  
- Build an app or online tool for vocabulary review

### 🤝 Collaboration & Suggestions

If you have suggestions to improve this project or want to contribute, I’d love to hear from you.  
You can contact me via email or in the comments section.

**Wishing you success in your German learning journey! 🇩🇪✨**

# 🇮🇷 فارسی

سلام!  
این پروژه شامل مجموعه‌ای از واژگان ضروری زبان آلمانی برای سطوح مختلف از **A1 (مبتدی)** تا **B2 (پیشرفته متوسط)** هست.  
هدف این مجموعه، کمک به زبان‌آموزان فارسی‌زبان برای یادگیری واژه‌ها به‌صورت کاربردی، ساده و دسته‌بندی‌شده است.

### 🎯 هدف پروژه

- ارائه واژگان مهم و پرکاربرد در هر سطح  
- ترجمه دقیق به فارسی و انگلیسی  
- ارائه جمله‌های نمونه برای درک بهتر فقط در A2 و B1  
- آماده‌سازی فایل‌ها برای مطالعه شخصی، کلاس درس یا آزمون‌های زبان

### 📂 ساختار فایل‌ها

هر سطح دارای یک فایل جداگانه است:

- `wortschatz_A1.md` → واژگان پایه برای شروع یادگیری  
- `wortschatz_A2.md` → واژگان روزمره با کمی پیچیدگی بیشتر  
- `wortschatz_B1.md` → واژگان کاربردی برای مکالمه و نوشتار  
- `wortschatz_B2.md` → واژگان پیشرفته برای تحصیل، کار و بحث‌های پیچیده

هر فایل شامل موارد زیر است:

- واژه آلمانی  
- ترجمه فارسی و انگلیسی  
- جمله نمونه (فقط در A2 و B1)  
- دسته‌بندی موضوعی (در صورت نیاز)

### 🛠️ نحوه استفاده

1. فایل مربوط به سطح خودت رو باز کن.  
2. واژه‌ها رو مرور کن و سعی کن جمله‌ها رو بخونی و درک کنی.  
3. واژه‌هایی که بلد نیستی رو یادداشت کن و تمرین کن.  
4. می‌تونی از این فایل‌ها برای ساخت فلش‌کارت، تمرین نوشتن یا مکالمه استفاده کنی.
