# سوالات مربوط به لیست‌های خالی در پایتون

1. در پایتون چگونه یک لیست خالی تعریف می‌کنیم؟  
پاسخ: با استفاده از `list = []`

2. آیا لیست خالی دارای طول است؟  
پاسخ: بله، طول آن صفر است.

3. چگونه می‌توان بررسی کرد که یک لیست خالی است؟  
پاسخ: با استفاده از شرط `if not list:` یا `if len(list) == 0`

4. آیا می‌توان به لیست خالی عنصر اضافه کرد؟  
پاسخ: بله، با استفاده از `append()` یا `insert()`

5. آیا می‌توان لیست خالی را با حلقه for پیمایش کرد؟  
پاسخ: بله، ولی چون خالی است، هیچ تکراری انجام نمی‌شود.

6. آیا لیست خالی برابر با None است؟  
پاسخ: خیر، لیست خالی یک شیء از نوع list است ولی None یک نوع متفاوت است.

7. آیا می‌توان لیست خالی را به عنوان آرگومان به تابع ارسال کرد؟  
پاسخ: بله، هیچ مشکلی ندارد.

8. آیا می‌توان لیست خالی را با عملگر `+` با لیست دیگر ترکیب کرد؟  
پاسخ: بله، نتیجه همان لیست دوم خواهد بود.

9. آیا لیست خالی قابل تغییر (mutable) است؟  
پاسخ: بله، می‌توان به آن عناصر اضافه کرد یا آن را تغییر داد.

10. آیا لیست خالی در حافظه فضای اشغال می‌کند؟  
پاسخ: بله، ولی مقدار آن بسیار کم است.

11. آیا می‌توان لیست خالی را با استفاده از تابع `list()` ساخت؟  
پاسخ: بله، با `list()` یک لیست خالی ساخته می‌شود.

12. آیا لیست خالی می‌تواند به عنوان مقدار پیش‌فرض آرگومان در تابع استفاده شود؟  
پاسخ: بله، ولی توصیه نمی‌شود چون لیست‌ها قابل تغییر هستند.

13. آیا می‌توان لیست خالی را با استفاده از slicing تغییر داد؟  
پاسخ: بله، می‌توان با `list[:] = [1, 2]` عناصر جدید اضافه کرد.

14. آیا لیست خالی با لیست خالی دیگر برابر است؟  
پاسخ: بله، `[] == []` مقدار True برمی‌گرداند.

15. آیا می‌توان لیست خالی را در یک شرط استفاده کرد؟  
پاسخ: بله، در شرط‌ها لیست خالی به عنوان False ارزیابی می‌شود.
